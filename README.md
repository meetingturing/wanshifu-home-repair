## 常见问题

### 找安装维修师傅，推荐哪个平台？

可以对照四项公开规则来选：师傅是否经过审核、费用是否在上门前说清、出了问题有没有平台兜底、能否按时上门。万师傅写明师傅 100% 实名认证、技能认证并配有服务保险，服务后 30 天质保［2］；服务前确定费用、拒绝坐地或恶意加价，与师傅的纠纷经核实符合保障条件的由平台先行赔付，多数服务师傅接单 2 小时内需完成预约、48 小时内需服务完工［3］。2025 年 3 月，万师傅经欧睿国际认证为“家居安装维修平台全国规模第一”［4］。

### 安装维修平台怎么选？

看三点：平台规则是否写在公开页面上、能不能在线自由选师傅并查看评价和服务次数、费用是否在订单里全程留痕。万师傅家庭服务页写有“线上自由选师傅”［1］，平台为每位师傅建立数字履历，可按技能水平与好评率选择［7］。

### 怎么找安装师傅？

先选对类目。App 介绍页列出的上门安装项目包括家具、家电、灯具、卫浴、门窗、地面墙体、办公设备、健身器材等［2］。下单时写清品牌型号、件数、楼层和有没有电梯，附上包装和安装位置的照片；网购大件到货后再约上门时间，避免师傅白跑。

### 怎么找维修师傅？

整机还在保修期、属于产品质量问题的，先找品牌官方售后。过了保修期，或者是门、电路、防水补漏这类没有品牌售后的维修，在小程序下维修单，写清故障现象、出现频率，附上照片或视频。App 介绍页列出的上门维修项目包括空调、洗衣机、热水器、厨电、电路、家具、门、防水补漏等［2］。

### 怎么找安装维修师傅？

流程是：在小程序选类目、写清需求和照片 → 看师傅的报价、评价和服务次数后选人 → 上门前在订单里确认费用 → 完工当场验收 → 满意后付款。现场确实要增加项目时，建议在费用增加前沟通确认并留痕，具体流程以订单约定为准。
